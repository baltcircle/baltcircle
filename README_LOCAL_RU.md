# TakeRide MVP — локальный запуск без VPN

Этот пакет запускает MVP велошеринга TakeRide на вашем компьютере или сервере без домена `pplx.app`. После запуска сайт будет доступен локально по адресу:

```text
http://localhost:5000
```

## Вариант A: запуск через Docker

Это самый удобный вариант, потому что не нужно отдельно ставить Node.js и зависимости проекта.

### Что установить

1. Установите Docker Desktop:
   - macOS: https://www.docker.com/products/docker-desktop/
   - Windows: https://www.docker.com/products/docker-desktop/
   - Linux: Docker Engine + Docker Compose plugin

2. Распакуйте архив проекта.

3. Откройте терминал в папке проекта `baltcicl`.

4. Скопируйте `.env.example` в `.env` и укажите как минимум `DATABASE_URL`
   (реальный PostgreSQL — локальный или managed). Приложение требует
   рабочее подключение к Postgres и не запустится без него — раньше здесь
   был предустановленный SQLite-файл, но БД полностью перенесена на
   PostgreSQL (см. `.env.example` и раздел «Важно» ниже).

### Команды

```bash
docker compose up --build
```

После запуска откройте:

```text
http://localhost:5000
```

Остановить:

```bash
docker compose down
```

Полностью сбросить данные: приложение хранит всё в PostgreSQL, на который
указывает `DATABASE_URL` — Docker Compose больше не создаёт свой volume с
базой (раньше `docker compose down -v` удалял локальный SQLite-volume, сейчас
этого volume не существует). Чтобы очистить данные, очистите/пересоздайте
саму базу Postgres, на которую вы указали в `DATABASE_URL`.

## Вариант B: запуск через Node.js

### Что установить

- Node.js 20 LTS или новее.

### Команды

```bash
npm install
npm run build
npm run start
```

Откройте:

```text
http://localhost:5000
```

Сбросить данные: как и в Docker-варианте, БД теперь PostgreSQL (см.
`DATABASE_URL` в `.env.example`), а не локальный SQLite-файл — очистите
таблицы в самой базе Postgres, на которую вы указали.

## Что внутри MVP

- стилизованная карта Балтийского побережья (Зеленоградск, Пионерский, Светлогорск) с велосипедами, станциями, зонами и велодорожками;
- QR-аренда;
- тарифы и демо-кошелёк;
- GPS-симуляция поездки;
- парк из 100 велосипедов;
- аналитика;
- сервисные заявки;
- светлая и тёмная тема.

## Важно

Это уже не прототип-заглушка: SMS/Email-OTP и OAuth (Яндекс ID, VK ID)
авторизация, реальные платежи через T-Bank/T-Kassa (привязка карт, оплата
поездок, шифрование данных карт в базе), реальная TCP-интеграция с
smart-lock замками (протокол OMNI) и управляемый PostgreSQL — всё это уже
работает в проде, не заглушка. Карта строится на реальных данных
MapLibre/OSM (PMTiles-экстракт региона).

Что по-прежнему упрощено/не хватает для полноценного масштабирования:

- роли пользователей ограничены (клиент/оператор/механик/админ через
  `ADMIN_PHONE_NUMBERS`, без отдельного UI управления ролями);
- нет мобильного приложения — только веб (PWA) с камерой браузера для QR;
- кэш активных поездок/парковок держится в памяти одного процесса (нет
  Redis) — при масштабировании на несколько инстансов нужна отдельная
  синхронизация.

## Перенос на сервер позже

Этот же Docker-пакет можно будет перенести на Yandex Cloud, Timeweb, Selectel или другой VPS. На сервере приложение обычно запускается на `localhost:5000`, а внешний доступ идёт через nginx по HTTPS.
